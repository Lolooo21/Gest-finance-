# Gest-finance

PWA de gestion des finances du foyer (reste à vivre, récurrences, fiches de paie, comptes bancaires, actualités).
Architecture : monorepo pnpm TypeScript (NestJS, React/Vite PWA, PostgreSQL, Redis, Docker). Voir `docs/` et le plan d'architecture.

## Démarrage
```
pnpm install
pnpm test
```
